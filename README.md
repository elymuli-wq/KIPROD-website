# KIPROD Website (Astro)

The KIPROD website — the digital operating layer of the KIPROD Institutional Strengthening Ecosystem — built with [Astro](https://astro.build/).

**Governing reference:** KIPROD Website Master Implementation Blueprint v1 (`../Assets/KIPROD WEBSITE MASTER IMPLEMENTATION BLUEPRINT v1.pdf`)

## Run locally

```bash
npm install
npm run dev
```

Astro will print a local URL (usually `http://localhost:4321`).
